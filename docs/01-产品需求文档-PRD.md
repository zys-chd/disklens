# DiskLens / 磁盘透镜 — 产品需求文档（PRD）

> v1.0 ｜ 2026-11-09 ｜ 状态：已确认方向，待 MVP 验收
> 项目路径：`~/Projects/disklens/`
> 决策来源：用户 2026-11-09 确认（技术栈 Rust+Tauri 2，首版全功能，个人自用，文档+MVP 交付）

---

## 1. 一句话定位

一个跨平台（Windows / macOS / Linux）的磁盘空间分析工具：**几秒内扫完一个分区，用你一眼就懂的方式告出"是谁占了我的空间"，并能安全地下手清理。**

对标的不是 `du -sh`，而是"能看清 + 敢动手"。

---

## 2. 用户与场景

| 项 | 内容 |
|---|---|
| 主用户 | 本人（开发者/工程师，Linux 桌面，NVMe 127G 分区长期 90%+） |
| 使用频率 | 空间告警时使用，约每周 1 次；偶发"空间莫名下降"时定位 |
| 典型场景 A | "我又红了，先看看谁最大" → 扫 /home，Treemap 一眼定位大头 |
| 典型场景 B | "这周涨了 20G，是谁涨的" → 扫描快照对比 |
| 典型场景 C | "这 3 个缓存目录能删" → 多选 → 移到回收站 |
| 典型场景 D | "这个文件我想打开看看/在文件管理器里定位" → 右键菜单 |

**关键洞察（迁移自既有 Python 版实测数据）**：占用最大的通常是**不能删**的东西（Steam 游戏 45G、/usr 26G），真正能回收的是缓存类。所以产品必须同时回答"谁大"和"这个敢不敢动"，而不是只给一个 du 排序。

## 3. 功能需求

优先级：P0 = MVP 必须；P1 = MVP 内尽量；P2 = 后置（本次不做，写在这里防止临时加需求）。

### 3.1 扫描与导航

| 编号 | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| F1 | 选择目标：目录选择器／拖入文件夹／列出本机挂载盘及容量 | 三入口都能发起扫描；盘列表显示 已用/总量/可用 | P0 |
| F2 | 递归扫描：全部子目录，统计每个节点 size/文件数/mtime | 与 `du -sx` 误差 < 0.5%（含硬链接场景） | P0 |
| F3 | 实时进度：已扫条目数、已扫字节、当前路径、耗时；可随时取消 | 进度 200ms 内刷新；取消后 1s 内停止线程并保留已扫结果 | P0 |
| F4 | 目录树：可展开/收起、按 大小/名称/文件数/修改时间 排序、升/降序 | 10 万行节点滚动 60fps（虚拟滚动） | P0 |
| F5 | 每行显示：名称、占比条、大小（SI 单位）、文件数、修改时间 | 单位自动 B/KB/MB/GB/TB（1024 进制，1 位小数） | P0 |
| F6 | 面包屑 + 双击下钻 + 返回上一级 + 回到根 | 任意深度可双向导航，状态不丢 | P0 |
| F7 | 搜索/过滤：当前树内按名称子串过滤（可只看 ≥N MB 的项） | 输入即过滤，< 100ms | P1 |

### 3.2 可视化

| 编号 | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| F8 | Treemap 矩形树图：面积 = 大小，层级下钻，点击联动树/面包屑 | 5000 个矩形渲染 < 200ms；hover 高亮 + 悬浮提示 | P0 |
| F9 | 旭日图（Sunburst）：径向层级分布，点击扇区下钻 | 同上；与 Treemap 共享当前节点 | P1 |
| F10 | 按文件类型/扩展名分布：Top 12 类型条形图 + 其余归"其他" | 与树数据一致，可点击过滤 Top-N | P1 |

### 3.3 明细与操作

| 编号 | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| F11 | Top N 大文件列表（N 可调 50/100/500），显示路径/大小/修改时间 | 点击定位到树中该文件父目录 | P0 |
| F12 | 右键菜单：打开文件（默认程序）、在文件管理器中显示、复制路径、复制名称 | 三平台均可用（Windows explorer /select、macOS open -R、Linux dbus FileManager1 + xdg-open 兜底） | P0 |
| F13 | 删除：多选 → **默认移到回收站**；永久删除需二次确认（输入目录名） | 回收站失败时不静默降级为删除，明确报错 | P0 |
| F14 | 删除前预览：列出将删除的条目、合计大小、跳过项（权限/被占用） | 报告逐项结果；失败项保留在列表中可重试 | P0 |
| F15 | 安全护栏：`/`、`/usr`、`/etc`、`$HOME` 根、`~/Projects`、Obsidian 仓库、`/System`、`C:\Windows` 永不可删 | 删除请求在 Rust 层被拒绝（不只是前端隐藏菜单） | P0 |
| F16 | 快照对比：保存本次扫描为快照；选择两个快照 → 输出"增长 Top N / 减少 Top N" | 76G/百万文件快照 < 15MB，对比 < 2s | P1 |
| F17 | 导出：当前树的目录表 + Top 文件表导出 CSV | 可被 Excel 直接打开（UTF-8 BOM），带表头 | P2 |

### 3.4 明确不做（本次范围外）

- 重复文件检测（需哈希，另立项目）
- sudo 提权清理（只展示命令，不执行）
- 自动更新、代码签名、notarization、多语言 i18n（个人自用）
- 磁盘健康/SMART、文件系统修复
- 云盘、网络盘特殊处理

## 4. 非功能需求

| 维度 | 指标 | 说明 |
|---|---|---|
| 扫描性能 | /home 76G、~100 万条目 ≤ 8s（NVMe 热缓存）；冷缓存 ≤ 60s | 基线：`du -sx ~` 实测耗时做对照 |
| 内存 | 100 万节点扫描峰值 RSS ≤ 350MB | 节点紧凑化（名称只存 filename、arena 索引、扩展名 intern） |
| 首屏 | 扫描完成后树首屏 ≤ 300ms；展开一层 ≤ 50ms | 关键：**不做整树 IPC 传输**，按需分页 |
| 交互 | 滚动 60fps；treemap 重绘 ≤ 200ms；任何操作有 ≤100ms 的视觉反馈 | |
| 安全 | 默认只读；删除默认回收站；root 拒绝；符号链接永不跟随；不跨文件系统（可开关） | |
| 健壮 | 权限拒绝/坏符号链接/文件名非 UTF-8 不中断扫描，计入 error 计数并在 UI 提示 | |
| 平台 | Windows 10+ / macOS 12+ / Linux（glibc 2.31+） | 个人自用：Linux 主测，另两平台构建验证 |

## 5. 界面布局（单窗口，可拖动分栏）

```
┌───────────────────────────────────────────────────────────────────────────┐
│ [盘▾] /home/zys ▸ Projects ▸ disklens        [搜索____] [⟳重扫]  ⚙        │ 顶栏/面包屑
├──────────────────────────────────────────────┬────────────────────────────┤
│ 目录树（虚拟滚动）                            │  [Treemap|旭日|类型]       │
│ ▾ Projects            3.4G  ████░░░░  42,183 │  ┌──────────────────────┐  │
│   ▸ reliability-tool  1.2G  ██░░░░░░   8,402 │  │   Treemap 矩形树图    │  │
│   ▸ disklens          0.9G  █░░░░░░░   6,110 │  │   （点击下钻）        │  │
│   ▪ huge.bin          780M  ▌░░░░░░░      1  │  └──────────────────────┘  │
├──────────────────────────────────────────────┴────────────────────────────┤
│ [Top 大文件] [快照对比]   50/100/500 条 │ 已选 3 项 · 合计 2.1G  [移入回收站]│ 下部面板
│ 780M ~/Projects/disklens/target/debug/…  ▸ 打开  在文件管理器中显示        │
└───────────────────────────────────────────────────────────────────────────┘
扫描中：▓▓▓▓▓▓░░░░ 62%  已扫 412,993 项 / 48.2G  当前：~/.cache/…  [停止]
```

设计要点：
- **左树下右图上**：文字精确、图形直观，互相联动（点 treemap 扇区 = 树跳到该节点）。
- **危险操作在底部右端集合**，与浏览区分开，避免误触。
- 深色/浅色跟随系统；配色用单一强调色（蓝紫）+ 语义色（safe 绿 / careful 黄 / danger 红）。
